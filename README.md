# Currency Converter

A simple and responsive web application to convert amounts between different world currencies.  
Built with HTML, CSS & JavaScript.

## 🔍 Features  
- Choose a **source currency** and a **target currency**.  
- Enter an amount and get the converted value instantly.  
- Clean, minimal UI that works on mobile and desktop.  
- Easy to extend: add more currencies, integrate live APIs, enhance UI.  

## 🛠 Technology Stack  
- HTML5 for structure  
- CSS3 for styling and responsive layout  
- JavaScript (vanilla) for logic and user interaction
